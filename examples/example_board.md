# Demo board

Text under the `#` title is the board description. It is kept in the file but not shown on the board.

## Backlog

Text under a `##` heading is the column description. Also kept, not shown.

### Try drag and drop

Drag cards between columns, or drag a column by its header.

### Flags are just emoji 🟥

Hover a card and press 1 to 8 to toggle a colored square in the title:
1 🟥 2 🟧 3 🟨 4 🟩 5 🟦 6 🟪 7 🟫 8 ⬜

### Search me

Press Ctrl+F and type "search". Cards that don't match fade out.

## Doing

### Write the report 🟧

The first line of text is shown as a preview on the card.

- [x] Collect numbers
- [x] Draft outline
- [ ] Write summary
- [ ] Send to team

The checklist above shows as ☑ 2/4 on the card.

### Code blocks are safe

Headings inside code fences are not parsed as columns or cards:

```
## This is not a column
### This is not a card
```

#### Deeper headings

Headings with four or more `#` stay inside the card description.

## Done

### Open this file in Kanban MD ✅🟩

Edit it in any text editor too. Changes are picked up when you switch back to the browser tab.

### Copy and paste cards 🟦

Hover a card, press Ctrl+C (or Ctrl+X), switch to another board tab, hover a column and press Ctrl+V.
